# Video Annotation Portfolio

## Project
Video annotation practice using CVAT.

## Work Performed
- Reviewed video frame-by-frame
- Created object annotations
- Added labels to video frames
- Tracked objects across frames
- Reviewed annotations for consistency
- Exported annotation data in JSON format

## Tools
- CVAT
- JSON
- Visual Studio Code

## Annotation Data
The annotations.json file contains:
- Frame/image information
- Object labels
- Bounding-box coordinates
- Category IDs
- Annotation IDs
